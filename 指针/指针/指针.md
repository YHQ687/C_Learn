# 内存和地址
## 内存
CPU处理数据时，需要的数据是在内存中读取的，处理后的数据也会放在内存中。  
为了方便访问，把内存划分为一个个内存单元，每个内存单元大小取**1个字节**
```t
bit  -比特位1/0 
Byte  - 8 bit
kB    - 1024Byte  2^10
MB    - 1024kB 
GB    - 1024MB
TB    - 1024GB
PB    - 1024TB
```
每个内存单元都有一个编号，相当于这个内存单元的地址，C语言中称他为**指针**  
因此 **内存单元编号** == **地址** == **指针**

# 指针变量和地址
## 取地址操作符&
```c
int main()
{
	int a = 10;
	printf("%p\n",&a);
	return 0;
}
```
在调试窗口中：打开内存窗口：输入&a查看a的地址以及内存中a的值（调试已经运行过int）
```text
10的二进制：00000000 00000000 00000000 00001010
10的16进制：   0   0    0   0    0   0    0   a
在内存中反向存放：即：0a 00 00 00
```
&a理论上说是取出a的地址，但因a占有四个字节，所以取出的是a最小的地址。

## 指针变量和解引用操作符(*)
### 指针变量
将&操作符得到的地址放入一个变量中，这个变量就叫指针变量。
```c
int main()
{
	int a = 10;
	iny* p =&a; 
	return 0;
}
```
```
// 下面三种写法完全相同：
int* p;
int *p;
int* p;    // (*p)是int类型

// 多个指针时的区别更明显：
int *p, q;      // p是指针，q是int（容易出错）
int* p, q;      // 看起来都是指针，但q实际上还是int
int *p, *q;     // 明确两个都是指针（最安全的写法）
```
```c
int main()
{
	int a =10;
	int* p = &a;
	printf("%d\n",*p);
	return 0;
}
```
`*`是解引用操作符，`*p`的意思是通过`p`里面存放的地址，找到`p`指向的对象，也就是`a`，所以`*p`就是`a`。
